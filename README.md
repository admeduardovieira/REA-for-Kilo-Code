# REA for Kilo Code

Reverse Engineering & Autonomous Auditing Framework for Kilo Code.

## Overview
An open-source auditing framework that extends Kilo Code with persistent memory, semantic code analysis, vulnerability detection, systematic debugging, and reproducible technical evidence.

## Structure
- `rea-core/` - REA 6.7.0 core
- `skills/` - Kilo Skills + Superpowers
- `memory/` - Engram
- `code-analysis/` - ast-grep + Serena
- `documentation/` - Context7
- `security/` - Gitleaks + OSV-Scanner
- `ci-analysis/` - actionlint
- `marketplace/` - Kilo Marketplace
- `integrations/` - MCP configurations
- `tests/` - Integration tests
- `.kilo/` - Agents and Skills

## Usage
Use the `rea-audit` skill/agent in Kilo Code to run systematic audits.
